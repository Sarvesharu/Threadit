Theoretical vs Empirical Performance Notes

As demonstrated above, algorithmic complexity determines how operations scale with dataset size:

  • Inverted Index: Eliminates linear text comparisons across all documents by directly looking up postings in an average O(1) custom HashMap bucket chain.
  • Min-Heap Top-K: Rather than sorting all N elements in O(N log N), maintaining a small min-heap of size K bounds the priority queue operations to O(N log K), yielding substantial speedups especially when K ≪ N.
  • Note on small datasets: On tiny in-memory datasets, Python interpreter bytecode overhead and CPU cache locality can introduce small variations. As dataset sizes scale, theoretical asymptotic boundaries dominate.
